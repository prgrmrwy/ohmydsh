# 方法论映射：固定虚构自检覆盖了什么

状态：随 change `dsh-memex-evaluation-harness` 引入，2026-10-28。
本文件只说明 [evaluation-methodology.md](evaluation-methodology.md) 中各原则在本次实现里的去向；原文不因本映射删除或改写，冲突时以原文为准。

去向含义：

- `implemented-selftest`：固定虚构自检实现了该原则的**链路检查部分**，不代表业务评估已完成。
- `deferred`：本次未实现，留在后续业务评估、校准与统计工作中；原文保留。
- `corrected`：原表述在实施时被收紧或纠正，理由见本行。首版不执行这些效果推断。

固定自检只回答“评估链路能否在受控输入下跑通并如实记录”，不回答 Memex 是否有效。

| ID | 原则 | 去向 | 理由 |
|---|---|---|---|
| M01 | 「以真实工具调用为主账」，按调用身份去重 | implemented-selftest | 递归审计按 origin 身份对 seed 去重，冲突指纹记为缺证；仅用于自检会话 |
| M02 | 「相关不等于贡献」 | corrected | 自检不把召回、读卡或结论一致计为贡献；R 层只接受程序性证据，语义裁判不得推出 R/W |
| M03 | 「未见不等于无用」，缺证标未知 | implemented-selftest | 缺失判据、缺日志、缺用量一律 unknown，报告非零退出，不当失败也不当通过 |
| M04 | 「证据要看区分度」，不做似然连乘 | corrected | 历史权重与似然比不是贝叶斯先验；首版不计算任何似然或后验 |
| M05 | 「评审分歧不投票」 | deferred | 自检每条件两项独立判据，不做多评审仲裁；仲裁流程留待业务评估 |
| M06 | 「记录齐全不等于验证深度一致」 | implemented-selftest | 报告区分已选可见答案事件、裁判实收与人工复核覆盖，后两者无证据时为 unknown |
| M07 | 「不用当前版本回填历史」 | deferred | 自检只用冻结的虚构资源，不涉及历史卡片版本 |
| M08 | 按记忆库「实际消费地点」出题 | deferred | 自检使用固定虚构仓库与唯一 eval cwd，不代表真实 workspace 分布 |
| M09 | 跨库是「独立的检测维度」 | deferred | 自检每条件只有一个隔离库，personal fallback 关闭；跨库检测留待后续 |
| M10 | 共库多仓库测「抗串仓」 | deferred | 固定自检只有单仓库 |
| M11 | 出题：题目由「不知道优化方案的独立会话出」 | deferred | 固定三题为人工编写的虚构题，不满足出题/留出要求 |
| M12 | 出题：间接题「列出禁用词」 | deferred | 固定题不按间接题规范构造，不能代表召回能力 |
| M13 | 出题：「题型至少包括」五类 | deferred | 只有 Know、Stale、Writeback 三题，不覆盖规定题型 |
| M14 | 卡片状态「有效、过期」等四类覆盖 | deferred | 自检只含有效与过期两种虚构状态作链路覆盖，干扰与缺失未覆盖，不满足原则要求 |
| M15 | 「必答事实 + 可接受根因」 | implemented-selftest | 题目冻结 requiredFacts，facts 判据据此判定；标准答案不进入被测仓库 |
| M16 | 漏斗分层指标，「每层只在上一层通过的题上计算」 | implemented-selftest | Know mem R→K、Act mem R→A 条件漏斗与全计划端点分母并列，未计划条件仍计 unknown |
| M17 | 「写入类指标必须在隔离库中测」 | implemented-selftest | 写回题只在唯一 eval 库测，W 独立分母；成功写入按时序分类 |
| M18 | 卡片是先验、代码是似然的「对待卡片的标准」 | corrected | “先验/似然/后验”仅为行为隐喻，自检不做概率计算；stale 题只检查是否以当前配置为准 |
| M19 | 「能用程序判定的不交给模型」 | implemented-selftest | 引文出处、身份、路线、成本、写入时序均由程序判定；裁判只做两项语义判据 |
| M20 | 裁判「引用原文片段，由程序逐字核对」 | corrected | 引文逐字匹配只证明出处存在，不证明语义支持或已读全文 |
| M21 | 裁判「尽量与被测 Agent 不同模型家族」 | deferred | 路线由用户在启动确认时选择，工具不强制家族差异 |
| M22 | 放量前「人工标注的小样本校准」 | deferred | 20–30 条校准与每轮 3–5 条人工复核未实现；报告标注“裁判未校准” |
| M23 | 「不出单一总分」，主报告为矩阵 | implemented-selftest | 自检报告无总分，逐条件列 R/K/A/W/端点 |
| M24 | 有效样本量按「主题数」计 | corrected | 主题应作为聚类建模，不能把主题数直接称为唯一有效样本量；自检不出样本量结论 |
| M25 | 「区间大部分重叠的变化不能算作改善」 | corrected | 区间重叠不是配对改善检验；首版不计算区间、收益或显著性 |
| M26 | 「改善」门槛在试点后确定 | deferred | 自检不定义改善门槛 |
| M27 | 防过拟合：「区分系统级修复与内容级修复」 | deferred | 自检不用于优化循环 |
| M28 | 防过拟合：「封存集」 | deferred | 无封存集；固定虚构题不得用于验收优化 |
| M29 | 防过拟合：「持续补充新主题」与主题分层抽取 | deferred | 自检题目固定不轮换，也不做主题分层抽样 |
| M30 | 「回到真实使用核对」，稳定性复核 | deferred | 跨轮稳定性与真实会话抽样留待后续 |
| M31 | 「评估默认只读」 | implemented-selftest | 自检只写自己的私有目录与唯一 eval 库，不改真实记忆库或检索实现 |
| M32 | 「从不可变快照重建记忆库」，无 remote、无共享链接 | implemented-selftest | 资源哈希校验后独占物化，本地 git init、无 remote/同步/链接 |
| M33 | 「测试流量必须可被日常统计排除」 | implemented-selftest | 公共哈希登记，recall-report、report.sh、weekly-insights 在归根前过滤 |
| M34 | 固定「被测 Agent 配置与裁判配置」，不经自动路由 | implemented-selftest | 首次提问前设为 MANUAL 并回读；普通请求路线只做事后审计，异常即停止 |
| M35 | 链接或读卡「到达上下文都算到达」 | corrected | 链接存在不等于目标事实到达；自检的 R 只认程序性证据，未证明时为 unknown |

## 明确留在后续的工作

业务评估、出题与留出、20–30 条裁判校准加每轮 3–5 条人工复核、主题统计与改善阈值、跨库检测、跨轮稳定性，均不在本次实现内，也不得因自检通过而被视为已完成。
