This directory holds the plugins this repository develops itself, each one an independent, removable unit. Read it to learn what a package must contain, how it is built and installed, and how its README is tiered; start from the plugin index in the [root README](../README.md) to pick a package.

Every subdirectory is one in-house customization unit that follows the community `dsh.bundle` standard:

```
packages/<name>/
  package.json        # declares dsh.bundle { patch: "./cordis.patch.yml" }; independent semver; ohmydsh.docTier
  cordis.patch.yml    # this plugin's composition row (part of the bundle)
  src/                # host / client code
  README.md           # English README; README.zh.md is its Simplified Chinese twin
  CHANGELOG.md        # independent change log
```

- Dependencies are installed once from the repository root with `npm install` / `npm ci`; the root `package-lock.json` is the only lockfile, so do not generate or commit a lockfile inside a package directory;
- For a TypeScript package, `src/` is the source of truth; `lib/` is generated by the root workspace build or by sync and stays gitignored; never commit JS, declaration or source-map build output;
- Installation: declare it in the manifest (`type: package, source: local, version: x.y.z`); sync builds on demand, then installs with `dsh plugin add file:<path>` and adds it to the profile bundles automatically;
- Sync rebuilds based on a hash of the source/configuration inputs and decides whether to reinstall from a hash of the publishable content; a build failure happens before the old deployment is removed;
- **When release semantics change, still bump the version in both `package.json` and the manifest**; a same-version source iteration is also reinstalled reliably thanks to the content hash;
- Release: git tag `<id>@<version>`; publishing to a registry for sharing is decided separately.

## README tiers

Every package declares a documentation tier in `package.json` as `"ohmydsh": { "docTier": "A" | "B" | "C" }`; tests fail when it is missing or invalid. Every package ships `README.md` (English) and `README.zh.md` (Simplified Chinese), which link each other in their first lines.
