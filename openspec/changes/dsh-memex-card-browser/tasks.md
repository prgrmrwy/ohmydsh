- [ ] 1.1 新增独立于 `runKernel()` 的长驻进程 runner（不修改现有 runner 的 timeout/SIGTERM 语义）
- [ ] 1.2 启动参数：强制本地界面模式、抑制自动开浏览器、注入 `MEMEX_HOME` 指向目标库、沿用 `LC_ALL=C/LANG=C`
- [ ] 1.3 stdin 使用 `'pipe'` 且不写不关（用 `'ignore'` 会让长驻进程立即 EOF 退出，见 pitfalls 第 2 条）
- [ ] 1.4 就绪判定：解析 stdout 的监听行取得**实际**地址；解析不到即判为启动失败，不回退到"假定等于请求端口"
- [ ] 1.5 回收：SIGTERM 终止；注册在插件 dispose 上确保插件停止时全部终止；不按端口/命令行相似性猜测归属
- [ ] 1.6 单测：配置了远端的库不会走托管重定向分支（否则服务不存在）；端口漂移时取到实际端口；stdin 形态正确；dispose 后无残留
