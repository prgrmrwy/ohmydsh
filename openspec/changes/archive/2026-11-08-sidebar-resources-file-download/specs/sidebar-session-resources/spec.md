# Spec Delta

## MODIFIED Requirements

### Requirement: 展示会话中产出的文件
系统 SHALL 从窗口快照的工具调用展示意图(diff 卡片,或 generic 卡片 kind 为 edit)的 follow-along 位置提取本会话产出的文件,与链接并列展示在「本次产出」分组:失败调用、读取类(含 delete/search/read)不产出;同一文件多次写入/编辑按首次出现保留一条;条目展示文件名与时间,点击 SHALL 经 better-sidebar 的编辑器 tab 打开该文件内容(与工作台文件面板点击文件同效:路径由 Host 按会话文件服务的实际解析根解析、per-path 去重;宿主未提供打开能力时降级为纯文本展示)。产物 SHALL 合并窗口快照增量与 Host 完整日志基线;Host 缺少工具展示器时仍按既有 first-party mutation 词表提取已成功完成的文件,不把未完成调用当产物。

#### Scenario: 写入的文件出现在产出分组
- **WHEN** 会话中某次工具调用以 diff 卡片写入 `src/a.ts`
- **THEN** 「本次产出」分组展示 `src/a.ts`,点击在 better-sidebar 编辑器 tab 打开文件内容

#### Scenario: 读取与删除不产出
- **WHEN** 会话中仅读取或删除过文件
- **THEN** 「本次产出」分组不包含这些文件

#### Scenario: 同一文件多次写入只保留一条
- **WHEN** 同一文件先写入后编辑
- **THEN** 产出分组仅一条该文件条目

#### Scenario: Host 无工具展示器时恢复历史产出
- **WHEN** 会话日志含已成功完成的 write/edit 调用，但 Host 不可获得对应 Agent 工具的展示器
- **THEN** 基线仍展示这些文件，保留首次产出顺序；失败与未完成调用不计入产出

## ADDED Requirements

### Requirement: 展示并复制会话文件的远端路径
系统 SHALL 在产出文件行显示文件名及路径，由 Host 按该文件所属会话解析完整路径。打开编辑器、复制路径及下载 SHALL 使用同一会话的文件身份；不得用浏览器设备路径或会话列表中的旧 cwd 替代 Host 解析。查询失败时 SHALL 保留原始路径并展示错误，不得把未解析的相对路径标为完整路径。

#### Scenario: Worktree 内的相对路径
- **WHEN** 文件记录为 `reports/result.pdf`，所属会话的实际执行根为 `/repo/.worktrees/task`
- **THEN** 路径显示并可复制为 `/repo/.worktrees/task/reports/result.pdf`，打开编辑器使用该完整路径

#### Scenario: 同名文件与特殊字符
- **WHEN** 两个文件名称相同但路径不同，或路径包含中文、空格、百分号、井号
- **THEN** 各行保留独立路径及操作对象，路径字符不被当作 URL 编码或片段解释

#### Scenario: 路径查询失败
- **WHEN** 文件不存在、不是普通文件或无权读取
- **THEN** 行保留原始记录路径并显示查询失败原因，其他文件行继续可用

### Requirement: 下载远端产出文件到当前设备
系统 SHALL 在每个产出文件行提供独立「下载」操作，通过所属会话的官方文件读取权限取得原始字节，再交给当前浏览器下载。保存 SHALL 保持二进制字节及文件名语义，不经 UTF-8 转码；Web SHALL 仅提示已请求浏览器下载，不宣称本地保存成功或返回本地目录。系统 SHALL 遵守官方读取大小限制，不下载截断内容，不增加任意 Host 文件读取接口。

#### Scenario: 跨机下载二进制文件
- **WHEN** 用户从本地浏览器连接远端 DSH 并下载含中文和空格文件名的 PDF、图片或压缩包
- **THEN** 当前浏览器收到原始文件字节与建议文件名，远端不生成额外副本

#### Scenario: 下载失败或超限
- **WHEN** 读取被拒绝、文件消失、目标为目录/符号链接、超过官方完整文件上限或连接中断
- **THEN** 不请求保存错误内容或截断文件，显示具体错误并允许用户重试

#### Scenario: 下载进行中重复点击
- **WHEN** 同一文件正在读取或请求保存
- **THEN** 该行显示忙碌状态并阻止重复操作，其他行仍可操作

### Requirement: 文件操作遵循会话生命周期
系统 SHALL 在切换会话或卸载文件行时取消旧路径查询与尚未完成的文件读取，忽略过期异步结果；旧会话文件不得显示到新会话，也不得因旧读取完成而发起新的浏览器下载。文件相关官方能力缺失时 SHALL 给出明确不可用反馈。

#### Scenario: 下载过程中切换会话
- **WHEN** 会话 A 的文件尚在读取，用户切换到会话 B
- **THEN** 取消 A 的读取，不发起 A 的下载或把 A 的路径/反馈显示到 B

### Requirement: 官方交付文件卡片提供下载入口
系统 SHALL 在对话的官方交付文件卡片右侧通过公开 actions 插槽提供独立下载按钮，卡片主体仍打开侧栏预览，既有原生打开操作保持可用。下载 SHALL 按卡片所属会话及声明的事件序号、原始文件索引匹配文件，复用 Session 文件读取和原始字节保存能力；没有 Host 桌面时仍 SHALL 可以下载。声明缺失、坐标不合法或跨会话时 SHALL 禁止下载，不能按同名文件或 DOM 内容猜测目标。

#### Scenario: 无远端桌面下载 Office 文件
- **WHEN** 远端没有可用桌面，卡片展示通过 present 声明的 DOCX 或 XLSX 文件
- **THEN** 卡片右侧提供「下载到本地」按钮，点击只下载该文件，不触发预览或远端应用打开

#### Scenario: 同名文件与显示顺序变化
- **WHEN** 不同目录的同名文件被声明，或卡片因去重、折叠改变展示顺序
- **THEN** 按声明的原始 seq/index 定位所点击文件，文件路径字符与原始字节保持不变

#### Scenario: 非法或过期卡片
- **WHEN** 卡片声明不可用、坐标不合法或 action URL 的会话与当前卡片作用域不一致
- **THEN** 下载按钮禁用，不读取其他文件
