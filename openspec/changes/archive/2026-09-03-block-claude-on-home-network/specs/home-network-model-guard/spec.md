## Purpose

在 DSH 主机处于已知家庭网络时，阻止用户把提示词发往 Claude 系列模型：发送前即把该会话输入框置为不可用并说明原因，作为部署侧的防手滑 affordance（明确不是安全边界）。网络位置的真相源是 DSH 主机的公网出口 IP，而非浏览器所在设备。

## ADDED Requirements

### Requirement: 网络位置真相源为 DSH 主机公网出口 IP

系统 SHALL 通过 host 半区注册的 Connection RPC channel（`authority: loopback`）向浏览器提供网络位置判定，判定依据为 **DSH 主机**的公网出口 IP。系统 MUST NOT 依据浏览器所在设备的地址、时区或任何浏览器侧信号推断网络位置。

判定结果对外 SHALL 只暴露分类结论（是否家庭网络）与该结论的新鲜度/降级状态；系统 MUST NOT 把公网 IP 原文写入持久化存储或会话历史。

#### Scenario: 浏览器与主机不在同一台机器

- **WHEN** 用户经 SSH 隧道从另一台设备的浏览器访问 DSH Web GUI，而 DSH 主机位于家庭网络
- **THEN** 判定结果为「家庭网络」，依据 DSH 主机出口 IP，与浏览器所在设备所处网络无关

#### Scenario: 判定结论不泄漏 IP 原文

- **WHEN** 浏览器取得网络位置判定
- **THEN** 该判定只包含分类结论与状态，不包含公网 IP 原文

### Requirement: 公网 IP 判定按时间缓存并在网络变化时失效

系统 SHALL 对公网出口 IP 的查询结果缓存，缓存有效期内的重复判定请求 SHALL 由缓存应答而不触发新的外部网络请求。系统 SHALL 保证并发的判定请求不会放大为多个并发外部查询。

缓存 SHALL 在以下任一条件下失效并在下次判定请求时重新查询：

1. 距上次成功查询超过固定 TTL；
2. 观测到**主机网络配置发生变化**——包括断网、重连、切换网络接口或本机活动 IPv4 地址集合变化。

条件 2 SHALL 独立于 TTL 生效：一次断网重连后的判定 MUST NOT 沿用重连前的缓存结论，即使 TTL 尚未过期。

#### Scenario: 有效期内不重复外呼

- **WHEN** 已有一次成功判定，且在有效期内连续发生多次判定请求（如用户反复切换会话或修改草稿）
- **THEN** 全部由缓存应答，外部 IP 查询服务只被访问过一次

#### Scenario: TTL 过期后刷新

- **WHEN** 距上次成功查询已超过 TTL，且发生一次新的判定请求
- **THEN** 系统重新查询公网出口 IP 并以新结果替换缓存

#### Scenario: 断网重连后立即重新判定

- **WHEN** 主机断网后重新连接（本机活动 IPv4 地址集合发生变化），且 TTL 尚未过期
- **THEN** 缓存失效，下一次判定请求触发重新查询，不沿用重连前的结论

#### Scenario: 并发请求合并

- **WHEN** 缓存为空且同时到达多个判定请求
- **THEN** 系统只发起一次外部查询，全部请求共享该次结果

### Requirement: 家庭网络判定在出口 IP 不稳定时保持 fail open

系统 SHALL 以「家庭网络特征集合」作为**允许拦截的白名单**：仅当观测到的出口 IP 明确命中该集合时才判定为家庭网络。观测到的出口 IP 未命中集合时，系统 SHALL 判定为「非家庭网络」并因此不拦截。

系统 MUST NOT 以「未命中已知的非家庭网络」反推为家庭网络。家庭网络特征集合为空时，系统 SHALL 恒不拦截。

#### Scenario: 出口 IP 在轮换池中且未命中家庭特征

- **WHEN** 主机所处网络的公网出口 IP 来自一个大范围轮换的地址池，历次查询返回互不相同且均未命中家庭网络特征集合
- **THEN** 系统判定为非家庭网络，输入框保持可发送

#### Scenario: 家庭网络特征集合尚未配置

- **WHEN** 家庭网络特征集合为空（尚未填入实际值）
- **THEN** 系统恒判定为非家庭网络，不禁用任何会话的输入框

### Requirement: 家庭网络与 Claude 系列同时成立时禁用发送

当且仅当**主机处于家庭网络**且**该会话当前选中模型属于 Claude 系列**时，系统 SHALL 把该会话的输入框置为不可发送（inert），并在输入框内显示说明被禁用原因的本地化文案。

判定 SHALL 以会话为单位：一个会话被禁用 MUST NOT 影响其他会话的输入框。

#### Scenario: 家里 + Claude 模型

- **WHEN** 主机出口 IP 属于家庭网段，且当前会话选中 Claude 系列模型
- **THEN** 该会话输入框不可发送，并显示禁用原因文案

#### Scenario: 家里 + 非 Claude 模型

- **WHEN** 主机出口 IP 属于家庭网段，但当前会话选中非 Claude 系列模型
- **THEN** 该会话输入框可正常发送，无禁用文案

#### Scenario: 非家庭网络 + Claude 模型

- **WHEN** 主机出口 IP 不属于家庭网段，且当前会话选中 Claude 系列模型
- **THEN** 该会话输入框可正常发送，无禁用文案

#### Scenario: 禁用只作用于命中会话

- **WHEN** 会话 A 选中 Claude 系列且主机在家庭网络，会话 B 选中非 Claude 系列
- **THEN** 只有会话 A 的输入框被禁用，会话 B 不受影响

### Requirement: 模型切换即时生效与解除

系统 SHALL 订阅官方 per-session 模型选择状态；用户在输入框模型选择器切换模型后，禁用状态 SHALL 在无需刷新页面、无需重启会话的前提下随之生效或解除。

#### Scenario: 切到 Claude 后立即禁用

- **WHEN** 主机处于家庭网络，用户把当前会话模型从非 Claude 切换为 Claude 系列
- **THEN** 输入框随即变为不可发送并显示原因，无需刷新页面

#### Scenario: 切离 Claude 后立即恢复

- **WHEN** 输入框因家庭网络 + Claude 被禁用，用户把模型切换为非 Claude 系列
- **THEN** 输入框随即恢复可发送，禁用文案消失

### Requirement: 判定不可用时 fail open

当网络位置判定无法取得结论时——包括 host 无 `connection` 服务、channel 未注册、外部查询失败、超时或返回无法解析的结果——系统 SHALL **不**禁用输入框（fail open）。

系统 MUST NOT 在判定不可用时把状态呈现为"已确认不在家庭网络"；降级原因 SHALL 可供诊断。系统 SHALL 在后续判定请求时重试，而不是永久停留在降级态。

#### Scenario: 外部查询失败

- **WHEN** 主机无法访问外部 IP 查询服务（断网或服务不可达）
- **THEN** 输入框保持可发送，不因判定失败而误伤正常使用

#### Scenario: headless 组合无 connection 服务

- **WHEN** DSH 以缺少 `connection` 服务的组合加载（如 headless）
- **THEN** host 半区不注册 channel 且不阻止其余 DSH 服务加载；客户端保持不禁用

#### Scenario: 降级后可恢复

- **WHEN** 一次判定因网络故障降级，随后网络恢复并发生新的判定请求
- **THEN** 系统重新查询并按新结论决定是否禁用，不停留在降级态

### Requirement: 拦截为客户端 affordance 而非强制边界

本能力 SHALL 只作用于 Web 客户端输入框的可发送性。系统 MUST NOT 声称阻止已由 Agent 发起的模型调用，也 MUST NOT 拦截 subagent 或其他非输入框路径的模型请求。

#### Scenario: 不影响 Agent 内部调用

- **WHEN** 输入框因家庭网络 + Claude 被禁用，而某个已运行的 turn 或 subagent 正在调用 Claude 系列模型
- **THEN** 该调用不受本能力影响，禁用只作用于用户输入框的新发送
