## Why

历史审计能显示记忆曾经返回或被阅读，却往往不能区分记忆、父任务和源码的贡献。长期目标是可重复的构造检测：在人审标准答案、固定输入和模型条件下，定位召回、应用、更新和废弃知识的断点。业务题目与结果保持私有。

前两轮 anvil 评审均为 REVISE。2026-10-27 用户明确授权继续，并接受进一步收缩：**本 change 只运行随工具发布、内容固定的虚构自检套件，保留 LLM 裁判；暂不开放任意套件、业务库、效果推断或优化门槛。** 先证明真实 Host 链路可用，再开放实际评估，不再用未经验证的隔离承诺支撑大平台。

## What Changes

- 在 dsh-memex 包新增 CLI `dsh-memex-eval selftest` 与 `report <round>`，以及仅负责运行/查看的 skill。首版不接受 suite 路径，不支持换题、封存集或自定义拓扑。
- 随包固定 3 道虚构题：有效知识 Know、过期知识 Act、观察写回。所有题都运行有/无记忆配对。自检报告只验证链路，**不得作为 Memex 效果、模型排名或系统改善证据**。
- 固定资源树和独立发布的哈希清单；读取叶子文件前拒绝嵌套软链接、硬链接和非常规文件，检查完整路径集合与内容哈希。目录名不能证明虚构来源。可信边界是本地安装的受信包，不防御用户同时篡改程序与哈希常量。
- 每题 × 条件 × 尝试用永久唯一的 cwd 和记忆库路径，从不复用或移动到共享槽位。利用现有 local-path scope 派生，加目录级 `fallback:false`；无记忆条件另加 `memory:false`。首版只测单库，跨库拓扑后续实现。
- 被测者保持普通顶层会话。显式 MANUAL 并回读，实际请求头逐条核验模型配置。其普通委派**只做事后审计**：递归收集后代请求、动作与成本；路线不符则整题“配置不符”。用户接受此首版限制；这不构成防外发边界，不能用于业务内容。
- 保留 LLM 裁判：专用最小父 preset + 官方 fresh spawn 子 Agent。仅允许结构化结果提交能力，无文件、命令、外部网络和委派能力；全局 mask 不替代 own 工具核验。不满足实际工具面时拒绝启动自检，不能以“全 unknown”宣告闭环成功。
- 默认模型只读记录与提示：明确提示 `session/selectModel` 会改日常默认选择，运行前确认；结束或下次启动发现待确认记录时告知原值与当前值，由用户手动恢复。**不提供自动恢复写接口**。
- 冻结实际输入副本、协议和运行计划，而非只保存哈希。续跑创建新尝试，不重发不确定请求；身份或后台资源无法收尾时停止并保留现场。
- 程序判定事件/字面事实，LLM 判语义；非空且带事件定位的引文只证明来源存在，不证明语义支持。记录实际交给裁判的片段和覆盖范围。
- 分开报告端到端共同终点与条件漏斗诊断。N/A 跳过上一不适用层；无记忆结果不以缺少召回判失败。自检不计算主题后验区间、不运行 20 题校准、不宣布质量门槛通过。长期校准与统计方法保留并明确延期。
- 测试流量从 recall-report、其库枚举包装脚本和 weekly-insights 全部默认排除；Host 侧记录递归后代，原始身份存私有运行账本，共享登记只存哈希。

## Capabilities

### New Capabilities

- `dsh-memex-evaluation`：固定虚构自检闭环、运行冻结与身份追踪、独立路径、模型与默认值披露、受限裁判、证据与报告。

### Modified Capabilities

- `dsh-memex-memory`：召回只读报告默认排除测试流量，保留原有只读与归属契约。

沿用 dsh-memex-scope 的目录关闭与本地派生能力，不修改 scope 算法。weekly-insights 与包装脚本的过滤由新能力要求覆盖。

## Impact

- 源码预期涉及 `packages/dsh-memex/src/eval/`、CLI、最小 Host eval 桥、固定夹具、测试；桥提供轮次登记、裁判启动/取消和默认值读取，**无默认值写操作**。
- 受管配置只改 `dsh.yaml` 与新增的 judge-minimal preset，经过 build 部署；本规划不改配置、构建或重启日常 Host。
- 修改 recall-report、`skills/memex-recall-report/scripts/report.sh`、`skills/weekly-insights/scripts/insights.mjs`；增加 memex-eval skill。
- 自检仍在普通 Host 上运行：文件/bash 权限未被隔离，**宿主真实文件仍可达**；固定虚构输入降低来源风险，不保证宿主资产或标准答案不可访问。报告和确认必须显著披露；出现已知真实路径访问即终止自检、标为污染，事后检测不是预防措施。
- 正常换题前仅归档已登记测试根、清空其队列并等待静止，不销毁根 Agent 或触碰日常会话；jobs 仅凭同一 Host generation 连续可信 completed/killed 释放证据放行，failed/缺证据均停止；认证沿用 Host authority/Origin/cookie，不额外承诺 socket 本机来源。永不复用路径消除“旧 cwd 自动指向新题”，但不能保证任意 shell 命令不会自行找到别题。
- 本次只创建规划文档；实现与 live 验收需后续明确 apply 授权。

## 后续工作

以下事项保留原方法论，不因收缩而删除；归档时转入后续 change：

1. 开放私有业务套件：真实文件/命令/委派访问边界、答案隔离、首次内容请求前的服务商限制，以及不改全局默认的模型选择通道。
2. 独立出题、人审 gold、固定源码版本、五类题与四种知识状态、跨库/共库与发布拓扑、主题留出、内容修复单独回归。
3. 20–30 人工标注校准及每轮 3–5 抽查，绑定模型、提示和证据协议；争议按来源仲裁，不以人或模型多数票为真相。
4. 正式报告与试点门槛：端到端分母、条件诊断、主题聚类与异质性、配对成本；区间重叠不作为改善检验，不把历史偏置样本当真实场景权重，不删除相同结果的负控题。
5. 重复运行稳定性：BACKLOG B051；当前 change 原有后续工作保持关联。未验证前单次变化不构成改善。
