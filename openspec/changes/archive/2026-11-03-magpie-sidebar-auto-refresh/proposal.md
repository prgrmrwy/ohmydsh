# 侧栏额度卡可配置自动刷新

## Why

常驻额度卡只在挂载、手动刷新、展开和页面重新可见时读取。长时间开着 DSH 时，读数会一直停在旧值。用户希望有一个可配置的自动刷新间隔：默认 5 分钟，可以改，也可以关闭。

## What Changes

- 新增 host 设置 `sidebarRefreshMinutes`：整数分钟，默认 `5`；`0` 表示关闭自动刷新；允许范围 `0–1440`，非整数或越界写入返回 400。
- 设置页「Sidebar usage」面板增加「自动刷新」分钟输入框（0 = 关闭），写入后侧栏卡片立即采用新间隔。
- 侧栏卡片按该间隔自动重新读取（静默更新，不清空旧读数）；页面隐藏时暂停，恢复可见时补一次；不发送 `POST {all:true}`（自动刷新只读取，不强制网关刷新）。
- 关闭自动刷新后行为回到 0.6.x：只在挂载/手动刷新/展开/页面重新可见时读取。

## Impact

- 行为：侧栏卡片新增定时读取；默认开启（5 分钟），与既有 60 秒 TTL、单一刷新入口共存。
- 规范：新增「侧边栏额度自动刷新」requirement，并修改 AMD4 的「禁止定时器」表述。
- 兼容：`sidebarRefreshMinutes` 缺失时按 5 分钟处理；设 0 与旧版行为一致。
