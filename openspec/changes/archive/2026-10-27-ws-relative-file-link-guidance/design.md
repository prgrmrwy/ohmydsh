## Context

现有活动绑定已用官方 systemPrompt.context 安装确定性文本；本次沿用同一入口。

## Goals / Non-Goals

目标是让新回复的文件链接避开重复前缀。工具路径保护、官方包、原生权限与历史消息不变。

## Decisions

只追加一条稳定指引：明确执行根相对路径与 Markdown 示例，并把适用范围限定为回复文件链接。无需拦截点击或覆盖官方函数。

## Risks / Trade-offs

Agent 可能未遵从 → 此改动属于输出指引，不宣称修复历史链接或保证所有模型输出。上线仍需部署更新后的插件；本次不部署，不宣称真实 GUI 点击已验收。
