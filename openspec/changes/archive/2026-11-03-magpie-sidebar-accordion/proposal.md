# 侧栏额度卡改为流内手风琴

## Why

0.6.0 的展开态是一层绝对定位覆盖层，会压在工作区列表与 Workspaces 标题上：内容被遮住，视觉上像一块浮在列表上的面板。用户更希望展开时"顶上去"——卡片在流内变高、把列表挤短，而不是盖住列表。

## What Changes

- 展开/收起改为手风琴：标题行保留，明细在卡内向下展开并占据真实布局高度；侧栏列表可用高度随之变小，但内容不被覆盖，列表仍可滚动。
- 只保留标题行一个交互面（刷新按钮除外）：点击标题行切换展开/收起；常驻卡正文与底部双箭头不再可点击，双箭头降级为纯视觉溢出提示。
- 明细自身限制高度（`min(60vh, 520px)`）并内部滚动，矮窗口不会吃掉整个侧栏。
- 侧栏收起态的 320px 浮层行为不变。
- 更新 README 截图（新增额度卡截图、刷新设置页截图）并升 0.6.1。

## Impact

- 行为：`packages/dsh-magpie-connector` 客户端侧栏卡；无 host 协议、设置或凭据变化。
- 规范：修改「侧边栏常驻额度卡」「侧边栏卡片的展开、收起与读取」两条 requirement。
- 兼容：`sidebarUsage` 设置与读取策略（60s TTL、无轮询）不变；已开启的部署升级后无需改配置。
