# 「本地服务」tab 视觉设计稿（tasks 16.14）

## 定位

- **它是什么**：DSH 右侧工作台里的一个小浏览窗口，用来查看 DSH 所在机器上的本机服务。
- **谁在用**：正在经 Cockpit 远程使用 DSH 的开发者。他面前的电脑和 DSH 所在的机器不是同一台。
- **主要任务**：输入一个本机地址，立刻看到对应的页面。整个功能起源于一个困惑：“127.0.0.1 到底指哪台机器？”界面要在每个状态下都把答案说清楚：**这里的本机是 Host**。

## 唯一的大胆之处：地址栏把“哪台机器”写进地址里

地址栏不是一个裸输入框，而是一条“路由”：左段是固定的 `Host` 机器标记（服务器图标 + 文字），中间一条细分隔线，右段是等宽字体的本机地址。用户每次看地址，都会同时读到“Host 上的 127.0.0.1:5173”。只有这一处使用强调色（图标着色）。其余部分都保持安静，跟随 DSH 自身的视觉。

```
┌────────────────────────────────────────────────────────┐
│ ‹   ┃ ▣ Host │ 127.0.0.1:5173/second               ⏎ ┃ │  工具栏 36px，底部一条细线
├────────────────────────────────────────────────────────┤
│ 页面和 DSH 同源：只打开你信任的服务。                  │  常驻信任提示，11.5px，三级文字色
├────────────────────────────────────────────────────────┤
│ （需要时出现）外部链接 / 错误：一行，与正文左对齐      │
├────────────────────────────────────────────────────────┤
│                                                        │
│  iframe（填满剩余高度，无边框）                        │
│                                                        │
└────────────────────────────────────────────────────────┘
```

## 色彩（只用 DSH 主题变量，亮色与暗色自动跟随）

| 用途 | 变量 |
|---|---|
| 面板底色 | `--dsw-alias-bg-layer-1` |
| 地址栏底色 | `--dsw-alias-bg-layer-2` |
| 细线与地址栏描边 | `--dsw-alias-border-l2`；聚焦时 `--dsw-focus-ring-color`，以 `--dsw-alias-state-business-primary` 兜底（DSH 在指针模式下会把前者置为透明，写法照搬 DSH 自身） |
| 文字 | `--dsw-alias-label-primary`（地址）、`--dsw-alias-label-secondary`（说明）、`--dsw-alias-label-tertiary`（信任提示、禁用） |
| 强调（只用于 Host 图标） | `--dsw-alias-brand-primary` |
| 错误标题 | `--dsw-alias-state-error-primary` |
| 按钮悬停 | `--dsw-alias-interactive-bg-hover` |

不引入任何新的颜色值，不用渐变，也不加阴影。

## 字体

- 界面文字沿用 DSH 的无衬线字体（继承即可，不另设）。工具栏 13px；正文说明 13px，行高 1.6；空状态标题 15px、字重 600。
- 地址本身用 `var(--ds-font-family-code)`，12.5px。等宽字体只用于“地址”这一种代码性内容，不用于标签或元信息。
- 一律用句首大小写，不用全大写标签，也不在标题前加小标题。

## 各状态

**空状态**（还没打开任何页面）：iframe 区域显示一段左对齐的说明，最大宽度 46ch，内边距 24px。
```
在 Host 上打开一个本机服务
这里的 127.0.0.1 指运行 DSH 的那台机器，不是你面前这台。

试试  127.0.0.1:5173   localhost:3000   127.0.0.1:8080
```
示例是等宽字体的文字按钮，点击后会填入地址栏并直接打开。这里不需要第二遍信任提示，工具栏下方已经有常驻提示。

**错误状态**：在 iframe 区域原位显示，不弹浮层。左对齐，上下依次是标题和说明：
```
这个地址返回的不是网页
127.0.0.1:8000/ 返回了 text/plain，状态 404。本地服务只能显示网页，换一个页面地址试试。
```
其它错误也用同样的结构：标题写发生了什么，说明写用户可以怎么做。状态码读不到时，说明里省略“状态 …”。地址解析错误（如“端口无效”）只在地址栏下方显示一行，不清空现有页面。

**外部链接**：在 iframe 上方显示一行，底色为 layer-2：`页面想打开外部链接 example.com` · 文字按钮「在新窗口打开」（就是 spec 要求的那个 `<a target=_blank>`）· 图标按钮「关闭」。

## 控件

- **返回**：28×28 的透明图标按钮，图标为左箭头（chevron）。可访问名称为「返回」。禁用时透明度 0.4，鼠标指针为 default。
- **打开**：地址栏右端的 24×24 图标按钮（回车符号），可访问名称为「打开」。回车键同样可以提交。
- 所有可交互元素都要有清晰可见的键盘焦点环。动效只用于按钮悬停时的底色变化，时长 120ms；`prefers-reduced-motion` 时关闭。
- 图标用内联 SVG 绘制，描边 1.5px，跟随 `currentColor`，不引入图标库。

## 实现约束

- 样式写在包内的一份 CSS 字符串里，挂载时以 `<style data-dshls-style>` 注入一次。选择器统一以 `.dshls-tab` 为前缀，避免污染 DSH。不再使用行内 style 对象，iframe 必需的 flex 布局除外。
- 不改变任何行为、`data-*` 钩子、可访问名称，也不改变测试依赖的文本（错误文案以 spec 为准）。既有测试必须保持全绿。
- 宽度在 320px 以下时，Host 标记只显示图标，文字隐藏，但保留在 `aria-label` 里。

## 自查（对照模板化默认风格）

- 用了模板化风格吗？没有暖奶油底配赤陶色，没有黑底荧光色，没有报纸式细线密排，没有卡片拼接，没有全大写小标签，没有用中点串起来的元信息，按钮文字后面也没有加 “→”。等宽字体只用在地址上。
- 先前版本里的一个默认做法已经改掉：错误信息原来是地址栏下方一行红字，现在只有标题用错误色，说明保持正常文字色，避免整块大面积红色。
- 按“出门前摘掉一件饰品”的原则，摘掉的是空状态里的第二遍信任提示。工具栏下方已经常驻一条，空状态不再重复。

## 实施修订（2026-11-24）

- 变量名按 DSH 主题（`dsh-client-ui-theme`）的实际定义更正：强调色 `--dsw-alias-brand-primary`，等宽字体 `--ds-font-family-code`，焦点环 `--dsw-focus-ring-color` 以 `--dsw-alias-state-business-primary` 兜底。原稿写的 `--dsw-alias-accent` 和 `--dsh-font-mono` 在 DSH 中不存在。
- iframe 是唯一允许写死颜色的地方：`color-scheme: light; background: #fff`。普通网页默认在白色画布上渲染，透明的 iframe 在暗色主题下会透出 DSH 的深色底，导致页面文字不可读（暗色截图中发现）。这里的白色代表网页的默认画布，不属于 DSH 界面的配色。
