## Cross-cutting conclusions

1. The 9 packages have both Host and Client impact except `dsh-session-title-copy` (client-only) and `dsh-subscriptions-sandbox-shim` (Host-only); those exceptions do not reduce the runtime audit surface.
2. All runtime declarations, peers and devDependencies must move atomically to `0.1.5-rc.2` after the source/API work is complete. A successful dependency resolution alone is not approval evidence.
3. Bundler externals mentioning `@deepseek-ai/dsh-client-runtime` are not by themselves proof of a fatal loader failure; each resulting bundle must be executed and its user-facing activation checked.
4. `dsh-pet` compatibility artifacts and `dsh-worktree-session` generic attachments are implementation blockers for the runtime batch. Their old source state must not be marked complete by a manifest-only update.
