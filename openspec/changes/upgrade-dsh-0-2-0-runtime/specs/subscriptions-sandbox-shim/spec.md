## MODIFIED Requirements

### Requirement: 会话历史一致性与恢复

清洗后的工具调用参数 SHALL 进入会话持久化历史；会话恢复（resume）后，派生消息中的工具调用参数 SHALL 仍为清洗后的值，不复活原始参数。

系统识别工具调用与其结果的对应关系时，SHALL 同时支持两种表示：所 pin 运行体把工具结果放在消息内容块中，或把工具结果表示为独立的工具消息（以调用 id 关联）。系统 MUST NOT 仅因结果的表示方式不同，就把已有结果的工具调用判定为孤儿并从历史中移除。

#### Scenario: 会话恢复
- **WHEN** 一个含清洗后工具调用参数的会话被恢复并继续
- **THEN** 派生历史中的该工具调用参数不含这两个键

#### Scenario: 工具结果为独立工具消息
- **WHEN** 运行体以独立的工具消息（带调用 id）表示工具结果，且历史中每个工具调用都有对应结果
- **THEN** 发往订阅 provider 的历史中这些工具调用全部保留，没有任何调用被当作孤儿移除

#### Scenario: 真正缺少结果的调用
- **WHEN** 历史中某个工具调用在两种表示下都找不到对应结果
- **THEN** 系统按既有孤儿处理语义处置该调用，对其余调用不产生影响
