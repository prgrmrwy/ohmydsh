## Coverage Notes

- All 59 rows are executable; none is `N/A — non-executable`. Count check: 26 session + 19 updates + 14 routing scenarios = 59.
- Shared fixtures: a fake npm registry (local HTTP server serving a real-shaped `/latest` document and tarballs, counting requests); a fake PATH `openspec` shim reporting a chosen version; a temporary authoritative checkout + isolated `DSH_HOME` for repo-level upgrade/sync tests; a deterministic in-process test routing provider with configurable result, delay and throw; one shared `parseAdapterBlock(content)` helper used by every block assertion.
- The "Pet exposure gap" row builds the real `SkillRegistry` with `createScope` (the same in-memory construction used in the review's reproduction) and registers a plain host-level control provider next to the adapter; the control row MUST list in the Pet-style scope, so a harness that stops exercising the real registry fails loudly instead of passing vacuously. This row asserts the gap EXISTS and is documented; it does not assert isolation.
- Upgrade crash tests inject a kill point after the source CAS via a test-only hook in the transaction helper and then run a fresh process against the same state to simulate a Host restart. The write set under test is exactly `packages/dsh-openspec/package.json` and the root lockfile.
- `L/` smoke tests are the only valid evidence for header-level claims (tool lists, cross-workspace discovery), per `docs/notes/dsh-plugin-integration-pitfalls.md`; they run against an isolated profile started as a managed background job and must not touch the running GUI at 127.0.0.1:3080. The "every producible session kind" row records, as an explicit gap, any kind the isolated profile cannot produce (notably a Locus child), instead of passing vacuously.
- Renderer-parity assertions compare adapter output against `renderOfficialBody` computed directly from the pinned official renderer in the test, so upstream upgrades re-baseline automatically instead of freezing golden files.
- Extra unit tests (argument quoting, cache corruption, semver edge cases, journal parsing) are welcome and not listed. The undeclared `scope` option dependency is NOT an optional extra: it is the mandatory row `scope_reaches_provider_get_at_model_and_gesture_call_sites_and_undefined_agent_gets_no_notice`.
